# AI Sentiment Analyzer

A complete machine learning project that fine-tunes a pre-trained Transformer model (`distilbert-base-uncased`) to perform sequence classification on text data.

## Features
- Fine-tunes Hugging Face Transformers using the `Trainer` API.
- Custom tokenization and text preprocessing pipeline.
- Local model saving and inference testing.
